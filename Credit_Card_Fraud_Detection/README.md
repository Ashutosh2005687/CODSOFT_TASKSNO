
# Credit Card Fraud Detection

## Objective
The objective of this project is to identify fraudulent credit card transactions using Machine Learning.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Machine Learning

## Algorithm
Logistic Regression

## Project Features
- Data Preprocessing
- Feature Scaling
- Handling Class Imbalance
- Model Training
- Fraud Detection
- Model Evaluation

## Evaluation Metrics
- Precision
- Recall
- F1-Score
- Confusion Matrix
- ROC-AUC

## Dataset
creditcard.csv

## How to Run

Install dependencies:

pip install -r requirements.txt

Run:

python main.py
