# Task 1 - Iris Flower Classification

## Objective
Train a machine-learning classifier to identify Iris setosa, versicolor, or virginica from sepal and petal measurements.

## Dataset
This project uses the Iris dataset bundled with scikit-learn, so no separate CSV download is required.

## Method
- Train/test split (80% / 20%)
- Feature scaling
- K-Nearest Neighbors classifier
- Accuracy, precision, recall, F1-score, and confusion matrix

## Run
```bash
pip install -r requirements.txt
python main.py
```
