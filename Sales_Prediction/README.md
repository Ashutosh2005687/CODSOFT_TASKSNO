
# Sales Prediction Using Python

## Objective
The objective of this project is to predict product sales based on advertising expenditure.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Machine Learning
- Linear Regression

## Features
- Data Loading
- Data Preprocessing
- Model Training
- Sales Prediction
- Model Evaluation

## Algorithm
Linear Regression

## Dataset
Advertising.csv

The dataset contains:
- TV
- Radio
- Newspaper
- Sales

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R-squared Score

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the project:

python main.py
